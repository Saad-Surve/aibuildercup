## 6. Gotchas discovered

- GCP has **no native hard spending cap**; budgets only alert. We built a kill switch.
- Cloud Text-to-Speech has **no IAM role** for the synthesis API; enabling the API is enough.
- The Cloud Storage service agent (`service-<num>@gs-project-accounts...`) does not exist until
  `gcloud storage service-agent` is run.
- Pub/Sub ack deadline max is **600 seconds**.
- Firebase ToS acceptance is console-only; `addFirebase` via API fails until it is accepted.
- Next.js 16 ships its own docs at `web/node_modules/next/dist/docs/` and an `AGENTS.md` that
  says to read them before writing code. Do that.
- `web/` is Bun; `backend/` is uv. Do not introduce npm/pip.
