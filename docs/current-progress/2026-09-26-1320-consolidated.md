### Reviewers / analysis (the flagship)

  `emotional_impact`, `conversion_cta`. The 6 retired values remain in `AnalysisDimension` as

- **Scoring is 1–5 integer** on findings; heatmap bins keep a float average. Colour bands in

  `findingType`/`severity`/`score`); `findingType` enum is injected per reviewer.
- Reviewer prompts mirror: `docs/reviewer-prompts.md` (generated, not runtime).

## 2. Decisions that shape the code

- **Contract-first.** Endpoints/schemas go into `contracts/openapi.yaml` before code.
- **Provider pattern.** External calls only through `backend/app/providers/`.
- **Agent Platform only.** Every LLM call is Vertex/Agent Platform with ADC; local and deployed
  differ only by model tier (`gemini-3.1-flash-lite` local, `gemini-3.8-flash` deployed).
- **Delete is real, not soft.** Project delete removes the GCS prefix and the Firestore
  recursive tree. Any new project-scoped data must live under
  `users/{uid}/projects/{projectId}/...` (or the matching object prefix) to be covered.
  Account deletion removes the whole user tree.
- **Ownership checked twice** — path scope + stored doc; mismatch is `404`, not `403`.
- **Playback streams direct from GCS** via signed URL; browser cache is a speed/offline layer.
- **STT lives in the `us` multi-region** because Chirp 3 is GA there, not `us-central1`.
- **Exception-first review output** changes the heatmap look (gaps are honest).
- **Colour is meaning:** monochrome chrome, one signal; landing page is the exception.

## 3. Gotchas (the important list)

### Infra / GCP / Terraform

- No native hard spend cap. Budget + killswitch (`infra/budget.tf`) detaches billing. Agent
  Platform Spend Cap is console-only and should sit below the project budget.
- `/healthz` is reserved by Google's front end — use `/readyz`.
- IAM changes can take 1–2 minutes to propagate.
- Cloud Run throttles CPU after the response by default; background workers need
  `--no-cpu-throttling` (set in the deploy workflow) or they freeze mid-job.
- Terraform has known perpetual diff: the budget wants `projects/538724167565` →
  `projects/habeas-codus` (API normalizes back). Harmless — don't chase it.
- Applying Firestore rulesets needs `firebaserules.rulesets.create` (the local ADC lacked it);
  the deployer SA / Firebase Rules Admin must apply those.

### Speech-to-Text / transcription

- `chirp_3` is GA on the `us` **multi-region**, absent from `us-central1`. Batch recognition;
  sync isn't used.
- V2 cannot auto-detect AAC in MP4/MOV/M4A → explicit `MP4_AAC`/`MOV_AAC`/`M4A_AAC` with
  non-zero sample rate + channel count (defaults 44.1 kHz stereo).
- Batch requires an explicit output config (`InlineOutputConfig`); per-file errors arrive
  in-band at `file_result.error`, and results are at
  `results[].inline_result.transcript.results[].alternatives[].words[]`.
- Ripper-muxed MP4s (micro-chunked `stsc`, bogus sample-entry rate) make STT return INTERNAL;
  the worker retries once via a pure-Python demux → clean `.m4a` staging under the project
  prefix (delete-path safe, temp object removed after).
- Diarization is language-gated; the provider retries once **without** it instead of failing.
  Live verification of `chirp_3` diarization labels is still pending — if labels come back
  empty, set `STT_ENABLE_DIARIZATION=false`.
- Existing transcripts have `speaker: null`; re-transcribe to populate.

### LLM / analysis

- Structured output works on the Agent Platform Gemini models; `complete_json` returns
  `LlmCompletion(data, usage)`; thinking tokens count as output (matches billing).
- Cost is estimated from an env price table. `gemini-3.8-flash` intro pricing (0.75/3.75) is
  scheduled to double on **2027-01-01** — update the vars then.
- `POST /analysis` returns `409 COST_CAP_EXCEEDED` past `max_project_cost_usd`.
- Legacy findings (0–10 float, `explanation`) are clamped/fallback-read, not migrated — old
  heatmaps look off until re-run.
- Findings are filtered in Python (bounded set); avoid composite indexes.

### Storage / caching / CDN

- Cloud Run can't sign V4 URLs directly; sign via IAM `signBlob`. Ignore the compute
  placeholder `"default"` SA email. Bucket CORS must cover the exact web origin.
- **Firebase Hosting caches rewrite responses by default** — a 404 from `/api/**` got
  `max-age=600` and the UI showed a stale "transcript not ready" forever. Fixed at the origin
  (`Cache-Control: no-store`, `Vary: Authorization`) and in `firebase.json` (`/api/**` headers).
  When a UI disagrees with Firestore, check `curl -D -` for `x-served-by: cache-*` first.
- Always send the Firebase `Authorization` header on the SSE stream (plain `EventSource` can't).

### Web / Next

- Next.js 16 docs live under `web/node_modules/next/dist/docs/` — read them.
- shadcn here is **Base UI**, not Radix.
- Static export → no dynamic routes; workspace is `/projects/view?projectId=…`.
- `useSearchParams` needs `<Suspense>`. localStorage-derived state must not diverge from the
  server snapshot (client-only trees can seed it in a lazy initializer).
- TanStack `refetchInterval` is skipped while the tab is hidden unless
  `refetchIntervalInBackground: true`; a query waiting for data to appear must set it. Two
  observers on the same key with different options conflict (`.find()`, not `.some()`) — the
  transcript query now lives in one shared hook, `use-project-transcript.ts`.
- video.js: never put `poster` in the player-init effect deps (it rebuilt the player on the
  React-owned node and the video vanished). The `<video>` node is created imperatively and
  owned by video.js.
- oxlint forbids sync setState-in-effect and assigning to `useMediaPlayer()` results.
- `<img>` over `next/image` is intentional for generated data-URL posters.
- Run `bun` only inside `web/` (a stray root `bun add` creates a root lockfile/node_modules).

### Tooling / CI

- `web/` uses Bun, `backend/` uses uv, `infra/` uses Terraform. Never mix in npm/pip/poetry/yarn.
- Deploy workflow: `changes` path-filter → parallel `api`/`web`; fail-open `if` conditions;
  gha layer cache (`mode=min`), bun/Next/npx caches; Node 24 action majors; third-party actions
  SHA-pinned. See §7 for numbers.
- `backend/` has no tests by rule; `ruff` + `mypy` are the backend checks.
