## 3. Key decisions

- **Contract-first.** `contracts/openapi.yaml` is frozen; endpoints/schemas are updated there
  first. Backend schemas use the contract's camelCase names directly.
- **Provider pattern.** Every external dependency is behind an interface with real + cassette
  implementations; `MOCK_MODE=off|auto|on`. Cassette key is
  `sha256(provider + model + promptVersion + canonicalRequest)`.
- **Ownership is checked twice** — path scoped to `ownerUid` and the stored doc re-checked;
  mismatch is `404`, not `403`.
- **Storage/Firestore behind narrow protocols** so unit tests use in-memory fakes.
- **Jobs nested under the project**, but `GET /jobs/{jobId}` is project-agnostic: the doc
  denormalises `jobId` and is found via a collection-group query.
- **Upload is two safety layers:** validate MIME/size before issuing the signed URL; verify the
  object exists before recording the asset. Confirming queues an idempotent `transcribe` job.
- **LLM is Gemini Developer API only** (no Vertex). `GEMINI_API_KEY`; model registry defaults to
  the rolling `gemini-flash-latest`.
- **Colour is meaning** (design thesis): monochrome chrome, one "signal" blue, severity/heatmap
  scale is the only other colour. The landing page is a deliberate marketing exception.
- **`web/` is a static export**, so dynamic routes are impossible — the workspace uses
  `/projects/view?projectId=…`.

## 4. Gotchas (the important list)

**Infra / GCP**
- No native hard spend cap; a kill switch Cloud Function detaches billing at the budget.
- Cloud TTS has no IAM role for synthesis; enabling the API is enough.
- `/healthz` is reserved by Google's front end on Cloud Run — it 404s at the edge. Use `/readyz`.
- Firestore data-access audit logs and Vertex data-access logs are off by default.
- IAM changes (e.g. granting `serviceAccountTokenCreator`) can take **1–2 minutes** to propagate.

**Deploy**
- `NEXT_PUBLIC_*` are baked at build time; the workflow passes them from repo variables.
- Terraform has pre-existing drift (the projects index isn't in state; the Terraform SA lacks
  `firebaserules.rulesets.create`); targeted `gcloud` applies were used. A future `terraform
  apply` should reconcile.

**LLM**
- Gemini 2.5 models are retired for new AI Studio keys; `gemini-*-pro` is quota-blocked on the
  free tier. Use `gemini-flash-latest`.
- Transient 503s happen; the provider retries 429/5xx with backoff (4 attempts).
- Recording cassettes must not happen in `off` mode and must never be fatal — a write failure in
  the container once discarded a good response.

**Storage / upload**
- Cloud Run credentials can't sign V4 URLs directly; signing goes through IAM `signBlob`.
- `compute_engine.Credentials` reports the placeholder `"default"` as `service_account_email`
  until a metadata request resolves it — never pass it through.
- Browser uploads need bucket CORS for the exact web origin, and the `PUT` carries
  `Content-Type: video/mp4` (not safelisted), so it triggers a preflight.
- Plain user ADC locally has no service-account identity; a configured signing SA is used.

**Web / Next**
- Next.js 16 ships its own docs under `web/node_modules/next/dist/docs/` — read them.
- shadcn here is **Base UI**, not Radix (grouping requirements, `render={<Button/>}`, etc.).
- `useSearchParams` must be wrapped in `<Suspense>` for the static export.

**Tooling**
- `web/` is Bun, `backend/` is uv — no npm/pip/poetry/yarn.
- Backend `.venv` once dehydrated (OneDrive); fix is `uv sync --reinstall` with servers stopped.

## 5. Production debugging log (all fixed)

   then the cassette writer trying to create `../fixtures/cassettes` in the container and
   discarding a successful response (recording now `auto`-only and non-fatal).

   normalises the base URL.
3. **Upload 500 / orphan assets** — Cloud Run couldn't sign V4 URLs; now signs via IAM signBlob,
   and the asset is written only after the URL succeeds.
4. **Upload 400 `Invalid form of account ID default`** — the compute-credential placeholder was
   passed as the signing account; now ignored in favour of the configured SA.
5. **Delete `INTERNAL_ERROR`** — the runtime SA lacked Firebase Auth admin; granted
   `roles/firebaseauth.admin`. `delete_account` covers the whole `users/{uid}/` prefix and document
   tree (verified live with a throwaway user).
