## 3. Key decisions

- **Contract-first.** Endpoints/schemas go into `contracts/openapi.yaml` first.
- **Provider pattern.** No Google SDK in feature code; `MOCK_MODE=off|auto|on`.
- **Ownership checked twice** — path scope + stored doc; mismatch is `404`, not `403`.
- **Playback streams direct from GCS** (signed URL, native seeking, no API egress); the
  browser cache is a speed/offline layer, keyed by asset and project.
- **Sidebar motion principle:** rows never change justification/padding/height — only the
  rail width tweens and labels fade. Anything that teleports gets pinned, not animated.
- **Colour is meaning:** monochrome chrome, one "signal" blue; landing is the exception.

## 4. Gotchas (the important list)

**Infra / GCP**

- No native hard spend cap; kill switch detaches billing at the budget.
- Cloud TTS has no IAM role for synthesis; enabling the API is enough.
- `/healthz` is reserved by Google's front end — 404s at the edge. Use `/readyz`.
- IAM changes can take 1–2 minutes to propagate.
- Terraform has pre-existing drift (projects index not in state; SA lacks
  `firebaserules.rulesets.create`); targeted `gcloud` applies were used.

**LLM**

- Gemini 2.5 retired for new AI Studio keys; `gemini-*-pro` quota-blocked on free tier.
  Use `gemini-flash-latest`. Transient 503s → provider retries 429/5xx (4 attempts).
- Never record cassettes in `off` mode; write failures must be non-fatal.

**Storage / upload**

- Cloud Run can't sign V4 URLs directly; sign via IAM `signBlob`. Ignore the compute
  placeholder `"default"` service-account email. Plain user ADC needs a configured SA.
- Browser `PUT` carries `Content-Type: video/*` (not safelisted) → preflight; bucket CORS
  must cover the exact web origin. Signed-URL `fetch()` from the browser works for the
  same reason (used by poster backfill, capped at 64 MB).
- Canvas taints on cross-origin video — capture only from `blob:`/same-origin sources.

**Web / Next**

- Next.js 16 docs live under `web/node_modules/next/dist/docs/` — read them.
- shadcn here is **Base UI**, not Radix (`render={<Button/>}`, etc.).
- Static export → no dynamic routes; workspace is `/projects/view?projectId=…`.
- `useSearchParams` needs `<Suspense>`. Client state from `localStorage` must not
  diverge from the server snapshot (external store or mount-gated reads).
- oxlint forbids sync setState-in-effect; derive render-time values, write state only
  from async continuations/events. Hooks above early returns.
- `<img>` over `next/image` is intentional for generated data-URL posters.

**Tooling**

- `web/` Bun, `backend/` uv. Backend `.venv` can dehydrate on OneDrive —
  `uv sync --reinstall` with servers stopped.
