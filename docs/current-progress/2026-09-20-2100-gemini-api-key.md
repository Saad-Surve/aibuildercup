## 3. How to use the free key

1. Create a key at https://aistudio.google.com/apikey.
2. Add `GEMINI_API_KEY=<key>` to `backend/.env` (do not commit it).
3. Restart uvicorn. The next real persona/analysis call goes to the Gemini Developer API, not Vertex.

If the free tier rate-limits `gemini-2.5-pro`, set `MODEL_ORCHESTRATOR=gemini-2.5-flash` for
development; `gemini-2.5-flash` has a much larger free allowance.
